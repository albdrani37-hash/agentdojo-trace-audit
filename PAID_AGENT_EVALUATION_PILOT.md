## The buyer problem

An AI-agent evaluation may report an aggregate pass rate without a directly reviewable account of which execution records were included, excluded, transformed, or counted. This proposed engineering pilot checks the *evidence trail* for selected claims within an agreed, authorized sample.

## A bounded work package

Subject to a written statement of work, the proposed pilot could cover:

1. **Scope and freeze:** agree one agent/evaluation workflow, a frozen benchmark or dataset snapshot, claims to check, and permitted access.
2. **Trace linkage:** document source event/trace schemas and source-to-derived record references for the agreed sample.
3. **Population accounting:** reconcile record counts, denominators, duplicates, exclusions, missing evidence, and reported classifications.
4. **Repeatable checks:** implement or run reproducibility and consistency checks where lawful data access and executable materials permit.
5. **Handover:** deliver a findings register, machine-readable summary, and concise decision brief, retaining `UNKNOWN` / `HOLD` outcomes when claims cannot be verified.
