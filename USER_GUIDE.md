# User guide

`prepare` safely extracts and identifies the declared source. `analyze` reconstructs records and denominators without reading expected counts. `validate` checks source hashes and partitions. `render` writes a human-readable report. `verify` compares the frozen demonstration with a regression receipt after analysis. `run_all` and `verify_all` compose these stages. Exit 0 is success; 2 is a scientific/input validation failure; 64 is command misuse.
